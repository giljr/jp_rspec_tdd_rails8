| **Helper**                        | **Use Case**                                                                                                       | **Scope / Context**                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Devise::Test::ControllerHelpers` | For **controller specs** where you need to simulate a signed-in user.                                              | Include it inside: `RSpec.describe SomeController, type: :controller`. Allows the use of `sign_in(user)` and `sign_out(user)` for authentication **only in controller tests**.                                                                                                                                                                                                                   |
| `Warden::Test::Helpers`           | For **Feature / Integration / Request / System specs** where you need to simulate authentication at the app level. | Works with Capybara and full-stack specs. <br><br>Lets you authenticate without using the forms: <br><br> **Login**: `login_as(user, scope: :user)` — this bypasses the UI and logs the user in directly. Fully compatible with Devise because Devise uses Warden internally. <br><br>**Logout:** You can clear the session programmatically using `logout(:user)`, or just `logout` if you have only one Devise scope. |
